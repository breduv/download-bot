# DW Bot

**Telegram-бот для поиска музыки и скачивания медиа по ссылкам**

![Python 3.12](https://img.shields.io/badge/Python-3.12-3776AB?logo=python&logoColor=white)
![aiogram 3](https://img.shields.io/badge/aiogram-3-2CA5E0?logo=telegram&logoColor=white)
![Docker Compose](https://img.shields.io/badge/Docker_Compose-ready-2496ED?logo=docker&logoColor=white)

DW Bot принимает название трека или ссылку, подготавливает аудио, видео либо
фотографии и отправляет результат прямо в Telegram.

</div>

## Возможности

| Запрос | Что вернёт бот |
| --- | --- |
| Название трека | Результаты поиска Spotify, затем MP3 с названием, исполнителем и обложкой |
| Ссылка Spotify | MP3 с метаданными и обложкой трека |
| Ссылка YouTube | Список доступных разрешений и вариант «Только звук» |
| YouTube Shorts | Готовое видео |
| YouTube Music | Аудио в MP3 |
| TikTok | Видео или фотогалерею; короткие ссылки раскрываются автоматически |
| Instagram и Pinterest | Видео по публичной ссылке |
| VK | Видео по публичной ссылке на клип (`/clip...`) |

Дополнительно бот умеет:

- работать в inline-режиме через `@username_бота <URL>`;
- использовать отдельные прокси для Telegram и медиасервисов;
- повторять неудачные запросы `yt-dlp` с YouTube cookies;
- отправлять TikTok-фотографии группами с учётом лимитов Telegram;
- удалять временные файлы сразу после отправки.

> Spotify используется для поиска и метаданных. Сам аудиофайл подбирает и
> скачивает `yt-dlp` по исполнителю и названию трека.

## Быстрый старт

Для запуска понадобятся Docker с Compose, токен Telegram-бота и данные приложения
Spotify: Client ID и Client Secret.

### 1. Настройте окружение

Создайте локальный `.env` из примера:

```bash
cp .env.example .env
```

В PowerShell используйте `Copy-Item .env.example .env`.

Заполните три обязательные переменные:

```dotenv
BOT_TOKEN=your-telegram-bot-token
SPOTIFY_CLIENT_ID=your-spotify-client-id
SPOTIFY_CLIENT_SECRET=your-spotify-client-secret
```

Docker Compose читает `.env` автоматически. Файл содержит секреты, поэтому он
должен оставаться только на машине, где запускается бот.

### 2. Запустите бота

```bash
docker compose up -d --build
docker compose logs -f download-bot
```

Остановить контейнер:

```bash
docker compose down
```

## Конфигурация

| Переменная | Обязательна | По умолчанию | Назначение |
| --- | :---: | --- | --- |
| `BOT_TOKEN` | да | — | Токен Telegram-бота |
| `SPOTIFY_CLIENT_ID` | да | — | Client ID приложения Spotify |
| `SPOTIFY_CLIENT_SECRET` | да | — | Client Secret приложения Spotify |
| `COOKIES_FILE` | нет | — | Имя Netscape-файла с YouTube cookies в каталоге `data/` |
| `MEDIA_PROXY` | нет | — | Прокси для Spotify, `yt-dlp` и `gallery-dl` |
| `TELEGRAM_PROXY` | нет | — | Прокси для подключения к Telegram Bot API |
| `LOG_LEVEL` | нет | `INFO` | Уровень логирования: `DEBUG`, `INFO`, `WARNING`, `ERROR` или `CRITICAL` |
| `SEARCH_LIMIT` | нет | `5` | Число результатов поиска Spotify, от 1 до 10 |
| `MAX_UPLOAD_SIZE_MB` | нет | `49` | Максимальный размер одного отправляемого файла |
| `INLINE_CACHE_CHAT_ID` | нет | — | ID служебного чата для временной загрузки inline-медиа |
| `IMAGE_TAG` | нет | `latest` | Тег Docker-образа, который использует Compose |

Пустые необязательные значения можно не менять в `.env.example` либо удалить из
своего `.env`.

### YouTube cookies

Cookies нужны не для обычной работы, а как запасной способ доступа: бот повторяет
с ними запрос, только если попытка без авторизации завершилась ошибкой.

1. Экспортируйте cookies в формате Netscape.
2. Сохраните файл как `data/youtube.cookies.txt`.
3. Добавьте в `.env`:

   ```dotenv
   COOKIES_FILE=youtube.cookies.txt
   ```

Указывайте только имя файла, без пути. При запуске через Compose каталог `data/`
монтируется в контейнер как `/app/data`. Если переменная задана, но файла нет,
бот остановится с ошибкой конфигурации.

> Cookies дают доступ к YouTube-сессии. Используйте отдельный аккаунт, не
> публикуйте файл и обновляйте его при истечении сессии.

## Inline-режим

Чтобы скачивать медиа из любого чата, включите для бота в BotFather:

1. Inline Mode командой `/setinline`.
2. Inline feedback командой `/setinlinefeedback`.
3. Для feedback выберите `100%`, иначе бот не будет получать все события выбора.

После этого отправьте в любом чате:

```text
@username_бота <URL>
```

Выберите результат «Скачать»: бот опубликует заглушку и заменит её готовым медиа.
Inline-режим принимает только ссылки, которые можно скачать без дополнительного
выбора. Обычные ссылки YouTube с выбором качества обрабатываются в личном чате с
ботом.

Если `INLINE_CACHE_CHAT_ID` не задан, пользователь должен хотя бы один раз открыть
бота в личных сообщениях — туда бот временно загружает файл перед inline-отправкой.
Вместо этого можно указать доступный боту служебный чат или канал.

## Как устроен проект

`SearchService` определяет тип запроса, обращается к Spotify за поиском и
метаданными либо получает форматы YouTube. `DownloadService` передаёт загрузку
нужному провайдеру: `yt-dlp` для аудио и видео, `gallery-dl` для TikTok-галерей и
резервной загрузки TikTok-видео. FFmpeg конвертирует медиа, а Mutagen записывает
теги и обложку в MP3.

```text
app/
├── bot/          # Telegram-обработчики, роутер и клавиатуры
├── core/         # Конфигурация и логирование
├── errors/       # Прикладные ошибки и сообщения пользователю
├── models/       # Модели треков, медиа и входных запросов
├── providers/    # Spotify, yt-dlp, gallery-dl и обработка обложек
└── services/     # Поиск, разбор ссылок и координация загрузок

main.py           # Точка входа
```

Медиа создаются во временных каталогах и удаляются после отправки, поэтому
постоянное хранилище для загруженных файлов не требуется.

## Локальная разработка

Окружение контейнера использует Python 3.12, FFmpeg, `ffprobe` и Deno. Для
локального запуска установите те же компоненты и убедитесь, что они доступны в
`PATH`.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python main.py
```

Настройки читаются из корневого `.env`. Cookies, если они нужны, также кладутся в
`data/`.

Быстрая проверка синтаксиса:

```powershell
python -m compileall -q app main.py
```

## Ограничения

- Приватные, удалённые и недоступные в выбранном регионе публикации могут не
  скачиваться.
- Изменения на внешних платформах иногда требуют обновления `yt-dlp` или
  `gallery-dl`.
- Итоговый файл должен укладываться в `MAX_UPLOAD_SIZE_MB` и ограничения
  Telegram.
- Скачивайте и распространяйте только те материалы, на которые у вас есть право.
