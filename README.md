# DW Bot

**Telegram-бот для поиска и скачивания аудио, видео и фотогалерей**

Ищет треки по названию, разбирает ссылки популярных платформ, предлагает
доступные форматы и отправляет готовые медиафайлы прямо в Telegram.

## Возможности

| Возможность | Описание |
| --- | --- |
| 🔎 **Поиск музыки** | Ищет треки через Spotify и показывает до 10 результатов |
| 🎧 **Готовое аудио** | Скачивает трек, конвертирует в MP3 и добавляет название, исполнителя и обложку |
| 🎬 **Выбор качества** | Показывает доступные разрешения YouTube и вариант «Только звук» |
| 🖼️ **Фотогалереи** | Отправляет TikTok-фотографии медиагруппами с учётом лимитов Telegram |
| 🍪 **Cookies для YouTube** | Повторяет запрос с cookies, если обычная загрузка или получение форматов завершились ошибкой |
| ⚡ **Inline-режим** | Принимает ссылки через `@username_бота <URL>` в любом чате |
| 🌐 **Раздельные прокси** | Поддерживает независимые прокси для Telegram и внешних медиасервисов |
| 🐳 **Готовый контейнер** | В образ уже входят Python, FFmpeg, `ffprobe` и Deno |

## Быстрый старт

Для работы боту нужны токен Telegram и данные приложения Spotify.

1. Переименуйте `.env.example` в `.env`.
2. Заполните обязательные переменные:

   ```dotenv
   BOT_TOKEN=telegram-bot-token
   SPOTIFY_CLIENT_ID=spotify-client-id
   SPOTIFY_CLIENT_SECRET=spotify-client-secret
   ```

3. Запустите бота:

   ```bash
   docker compose up -d --build
   ```

## Настройки

| Переменная | Обязательна | По умолчанию | Назначение |
| --- | :---: | ---: | --- |
| `BOT_TOKEN` | да | — | Токен Telegram-бота от BotFather |
| `SPOTIFY_CLIENT_ID` | да | — | Client ID приложения Spotify |
| `SPOTIFY_CLIENT_SECRET` | да | — | Client Secret приложения Spotify |
| `COOKIES_FILE` | нет | — | Имя Netscape-файла из каталога `data/` для повторных YouTube-запросов |
| `MEDIA_PROXY` | нет | — | Прокси для Spotify, `yt-dlp` и `gallery-dl` |
| `TELEGRAM_PROXY` | нет | — | Прокси подключения к Telegram Bot API |
| `LOG_LEVEL` | нет | `INFO` | `DEBUG`, `INFO`, `WARNING`, `ERROR` или `CRITICAL` |
| `SEARCH_LIMIT` | нет | `5` | Количество результатов Spotify, допустимо 1–10 |
| `MAX_UPLOAD_SIZE_MB` | нет | `49` | Максимальный размер одного медиафайла |
| `INLINE_CACHE_CHAT_ID` | нет | — | Чат или канал для служебной загрузки inline-медиа |
| `IMAGE_TAG` | нет | `latest` | Тег Docker-образа, используемый Compose |

Если `COOKIES_FILE` не задан, повторные YouTube-запросы с авторизацией отключены.

### YouTube cookies

1. Поместите Netscape-файл в `data/youtube.cookies.txt`.
2. Добавьте в `.env` значение `COOKIES_FILE=youtube.cookies.txt`.

Каталог `data/` находится в корне проекта. В `COOKIES_FILE` указывайте только имя
файла; если он не найден, бот не запустится.

## Inline-режим

В BotFather включите:

1. Inline Mode командой `/setinline`.
2. Inline feedback командой `/setinlinefeedback`.
3. Для feedback выберите 100%, иначе бот будет получать не все события выбора.

После этого пользователь может написать:

```text
@username_бота <URL>
```

Бот покажет временный результат «Готовлю файл...», скачает медиа и заменит его
готовым файлом. Обычные ссылки YouTube, для которых нужно выбрать качество,
обрабатываются в личном чате с ботом.

Если `INLINE_CACHE_CHAT_ID` не задан, пользователь должен хотя бы один раз открыть
бота в личных сообщениях, чтобы Telegram разрешил служебную загрузку.

## Структура проекта

```text
app/
├── bot/          # Обработчики Telegram, роутер и клавиатуры
├── core/         # Настройки и конфигурация логирования
├── errors/       # Прикладные исключения и публичные сообщения
├── models/       # Типы запросов и медиа
├── providers/    # Spotify, yt-dlp, gallery-dl и обработка обложек
└── services/     # Разбор запросов и координация скачивания
```

Точка входа — `main.py`. Загруженные файлы создаются во временных каталогах и
удаляются после отправки, поэтому постоянное хранилище медиа боту не требуется.

## Безопасность и ограничения

- Не публикуйте `.env`, YouTube cookies и данные авторизации прокси. При утечке
  замените соответствующие токены и завершите скомпрометированную сессию.
- Приватные, удалённые и недоступные в регионе материалы могут не скачиваться;
  cookies и `MEDIA_PROXY` не гарантируют доступ.
- Изменения на внешних платформах могут потребовать обновления `yt-dlp` или
  `gallery-dl`.
- Размер файла ограничен значением `MAX_UPLOAD_SIZE_MB` и лимитами Telegram.
- Скачивайте и распространяйте только материалы, на которые у вас есть право.
